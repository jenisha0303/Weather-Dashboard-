🌤️ Weather Dashboard

A responsive Weather Dashboard that fetches real-time weather data using the OpenWeatherMap API.

🔗 Live Demo

https://jenisha0303.github.io/Weather-Dashboard-/

🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- OpenWeatherMap API
- GitHub Pages

✨ Features

- Search for weather details by city name
- View temperature, humidity, and wind speed
- Display weather conditions and icons
- Responsive user interface
- Handle invalid city names

⚙️ How to Run Locally

1. Clone this repository:
   git clone https://github.com/jenisha0303/Weather-Dashboard-.git
2. Open the project folder.
3. Open "index.html" in your browser.
4. Configure your OpenWeatherMap API key in the JavaScript file if required.

📁 Project Files

- "index.html" – Main webpage structure
- "style.css" – Styling and responsive layout
- "script.js" – Weather API integration and functionality
